The class ObjectArray will hold all the data (json), column names (array), logic plan (array) as its data member. As JS doesn't have any synchronous way of reading / writing files, so I thought about storing the operations along with file reads into the logic plan. And then all those objects into an static array (pipelines) of the class. I thought about putting the objects into an static array so that all asynchronous operations don't trigger simultaneously (I can call them using await), this way the if more than 1 files are read into different pipelines & then those pipelines are used in common operation like join, then the common operation's pipeline will not trigger unless the previous are completed.

-----------------------------------------------------------

NOTE: first implement without 'static pipelines'. see when this becomes necessary. then implement this.
      This is a really powerful approach for
	- managing depedency pipelines
	- preventing asynchronous pipeline execution
	- allows system to have full control over all the pipelines for
		observation (monitoring),
		access between pipelines (dependency),
		triggering (gives user a way to control pipeline execution order & parallelism using asynchronous calls)
