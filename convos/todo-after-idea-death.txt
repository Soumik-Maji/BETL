📦 ObjectArray Data Transformation Library – Design Summary
1. Data Structure
    Each ObjectArray instance contains:
    originalData: Deep copy of input data (array of objects from CSV)
    operations[]: Array of transformation descriptors (e.g., rename, update, sort)

2. Transformation Pipeline
    Methods like .renameMany(), .updateColumn(), .sort(), etc.:
    Don’t execute immediately
    Append operation descriptors to operations[]
    Return this (same instance) for chaining
    Methods mutate operations[] only, not the data

3. Execution
    .execute():
    Deep copies originalData
    Applies all operations in order
    Clears operations[] of the current instance
    Returns a new ObjectArray containing the transformed data and an empty operations array

4. Immutability via Cloning
    clone() method:
    Returns a deep clone of the current ObjectArray (copies both data and operations)
    Allows parallel pipelines/branches from any intermediate point

5. Logger Method
    .showHTML(label):
    Logs or displays current pipeline state (data preview)
    Doesn't alter the data or the pipeline
    Useful for debugging in-browser

6. Stateful vs Immutable Design
    Design is stateful, not purely functional
    Allows in-place chaining for convenience
    Encourages explicit control via .clone() to preserve immutability when needed

🚀 Optimization Strategy (For Later)
Goals:
    Reduce number of data passes
    Optimize memory use
    Speed up execution for large datasets

Techniques:
    Operation Fusion: Merge compatible steps (e.g., multiple updateColumn() calls into one loop)
    Execution Planning: Compact operations[] into a minimal instruction set
    Column Tracking: Avoid processing untouched columns
    Single-Pass Execution: Convert pipeline into a single iteration where feasible

🧩 Optional Enhancements
    .reset() – Restore to original data & clear operations[]
    .clear() – Only clears operations[] without affecting original data
    .execute({ inplace: true }) – (Advanced) Apply operations without deep copying
